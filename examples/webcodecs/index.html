WebCodecs AV1 → stillcast expand input adapter

Encodes ~1 s of a still image with VideoEncoder(av01.*), scans the produced temporal units for an anchor (sequence header + shown KEY_FRAME) and a golden (first shown non-key frame coded after it), then writes an IVF ordered [anchor, golden, ...rest] — the positional shape stillcast expand consumes. See docs/input-contract.md.
